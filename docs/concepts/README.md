# Notas técnicas consolidadas

[Índice](../index.md) · [Plantilla de concepto](../templates/concept.md)

Esta carpeta recibirá notas que permitan comprender un problema, comparar alternativas o defender una decisión.

## Qué necesita una nota

- Una pregunta o problema delimitado.
- Una definición operativa y un modelo mental claro.
- Alternativas y condiciones para elegirlas.
- Trade-offs, límites y fallos frecuentes.
- Fuentes originales que respalden las afirmaciones.
- Evidencia o experimento relacionado cuando exista.
